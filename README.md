# BizTax - Chartered Accountant & Tax Administration Portal

A high-performance, responsive React admin portal for managing taxpayer returns, Chartered Accountant (CA) onboarding and allocation, service catalog tiers, and invoice tracking.

## 🚀 Key Features

- **Dashboard & Analytics:** Live operational metrics for active cases, pending CA assignments, documents under review, and completed filings.
- **Case Management:** Real-time filtering, stage progression tracking, and automated / manual CA allocation.
- **Chartered Accountant Network:**
  - ICAI-verified CA onboarding with credentials and workload distribution.
  - Account password and confirmation security checks.
  - Dynamic capacity monitoring and real-time status management.
- **Service Catalog:** Tax advisory, ITR filing tiers, and document requirement management.
- **Global Search:** Fast instant filter across taxpayer records, case IDs, and CA profiles.
- **Settings & Security:** Admin credential management and access controls.

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Pure Standard CSS (Zero Tailwind, fully modular and responsive)
- **Icons:** Lucide React

## 📦 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Run the local development server
npm run dev

# Build for production
npm run build
```
